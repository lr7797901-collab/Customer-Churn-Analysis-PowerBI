## 📌 Project Overview

This project is an **end-to-end Telecom Customer Churn Analysis** developed using **SQL, Power Query, DAX, and Power BI**.

The project analyzes approximately **1 million customer records** to understand customer churn behavior, identify high-risk customer segments, and measure the financial impact of customer attrition.

The complete analytics workflow follows:
